# Асинхронные методы

**Когда читать:** при написании и ревью клиентского асинхронного кода.

Механизм `Асинх` / `Ждать` доступен с платформы 8.3.18. Версию проекта смотреть в
`platformVersion` в `.1c-workflow.json`; на более ранних версиях применяется
`ОписаниеОповещения`. Запрет модальных вызовов — [architecture.md](architecture.md).

## Основы

1. Асинхронная функция (суффикс `Асинх` в имени метода платформы) возвращает
   `Обещание`.
2. `Ждать` — оператор ожидания. Код после него не исполняется, пока обещание не
   завершится.
3. Методы `*Асинх` можно вызывать **только внутри** процедур и функций, объявленных
   с ключевым словом `Асинх`.
4. Обещание имеет три состояния: ожидание, успех, провал.
5. Механизм работает **только на клиенте**.

## Соответствие старых и новых методов

| Модальный (запрещён) | Через оповещение | Новый асинхронный |
|---|---|---|
| `Предупреждение()` | `ПоказатьПредупреждение()` | `ПредупреждениеАсинх()` |
| `Вопрос()` | `ПоказатьВопрос()` | `ВопросАсинх()` |
| `ОткрытьЗначение()` | `ПоказатьЗначение()` | `ОткрытьЗначениеАсинх()` |
| `ВвестиЧисло()` | `ПоказатьВводЧисла()` | `ВвестиЧислоАсинх()` |
| `НайтиФайлы()` | `НачатьПоискФайлов()` | `НайтиФайлыАсинх()` |
| `ПоместитьФайлы()` | `НачатьПомещениеФайлов()` | `ПоместитьФайлыНаСерверАсинх()` |

Смешивать `Асинх` / `Ждать` с неасинхронными аналогами внутри одной асинхронной
процедуры запрещено.

## Что возвращает Ждать

| Метод | Результат `Ждать` |
|---|---|
| `ПредупреждениеАсинх` | `Неопределено` |
| `ВопросАсинх` | `КодВозвратаДиалога` |
| `ОткрытьЗначениеАсинх` | `Неопределено` |
| `ВвестиЧислоАсинх` | `Число` |
| `НайтиФайлыАсинх` | `Массив` объектов `Файл` |
| `ПоместитьФайлыНаСерверАсинх` | `Массив` описаний помещённых файлов либо `Неопределено` при отказе |

## Базовый шаблон

```bsl
&НаКлиенте
Асинх Процедура ПодтвердитьИВыполнить()

	Обещание = ВопросАсинх(НСтр("ru = 'Продолжить?'"), РежимДиалогаВопрос.ДаНет);
	Результат = Ждать Обещание;

	Если Результат = КодВозвратаДиалога.Да Тогда
		// действие
	КонецЕсли;

КонецПроцедуры
```

## Без Ждать исключение теряется молча

Если асинхронная функция вызвана без `Ждать` и внутри возникло исключение, оно
**исчезает без следа**. Код продолжается как будто ничего не произошло.

```bsl
// Опасно: исключение внутри теряется
Процедура МояПроцедура(Команда)
	ВызватьОшибку();
КонецПроцедуры

Асинх Функция ВызватьОшибку()
	ВызватьИсключение "ошибка";  // этого никто не увидит
КонецФункции
```

**Правило.** Использовать `Ждать` всегда, когда важен результат или обработка
ошибки. Обходиться без `Ждать` только там, где и результат, и ошибки игнорируются
намеренно.

## Асинх в обработчике события формы не работает

Обработчики событий формы (`ПриОткрытии`, `ПередЗакрытием`,
`ПриЗаписиНаСервере` и прочие), объявленные с `Асинх`, ведут себя не так, как
ожидается: платформа не ждёт их завершения.

```bsl
// Не работает: форма откроется, Отказ = Истина проигнорирован
&НаКлиенте
Асинх Процедура ПриОткрытии(Отказ)
	Отказ = Истина;
	ВызватьИсключение "ошибка";
КонецПроцедуры
```

**Правило.** Обработчики событий формы асинхронными не делать. Вместо этого из
обычного обработчика вызывать отдельную `Асинх` процедуру.

Обработчики команд формы асинхронными делать можно.

## Вопрос при открытии формы

```bsl
&НаКлиенте
Процедура ПриОткрытии(Отказ)
	ЗадатьВопросПриОткрытии();
КонецПроцедуры

&НаКлиенте
Асинх Процедура ЗадатьВопросПриОткрытии()

	Обещание = ВопросАсинх(НСтр("ru = 'Продолжить работу?'"),
		РежимДиалогаВопрос.ДаНет, , КодВозвратаДиалога.Да);
	Результат = Ждать Обещание;

	Если Результат <> КодВозвратаДиалога.Да Тогда
		ЭтаФорма.Закрыть();
	КонецЕсли;

КонецПроцедуры
```

## Вопрос при закрытии формы

Флаг предотвращает рекурсию: `Закрыть()` из асинхронной процедуры снова вызывает
`ПередЗакрытием`.

```bsl
&НаКлиенте
Перем ВопросПриЗакрытииЗадан;

&НаКлиенте
Процедура ПередЗакрытием(Отказ, ЗавершениеРаботы, ТекстПредупреждения, СтандартнаяОбработка)

	Если Не ВопросПриЗакрытииЗадан Тогда
		ЗадатьВопросПриЗакрытии();
		Отказ = Истина;
	КонецЕсли;

КонецПроцедуры

&НаКлиенте
Асинх Процедура ЗадатьВопросПриЗакрытии()

	Обещание = ВопросАсинх(НСтр("ru = 'Закрыть форму?'"),
		РежимДиалогаВопрос.ДаНет, , КодВозвратаДиалога.Да);
	Результат = Ждать Обещание;

	Если Результат = КодВозвратаДиалога.Да Тогда
		ВопросПриЗакрытииЗадан = Истина;
		ЭтаФорма.Закрыть();
	КонецЕсли;

КонецПроцедуры

ВопросПриЗакрытииЗадан = Ложь;
```

## Работа с файлами

```bsl
&НаКлиенте
Асинх Процедура ЗагрузитьФайлыНаСервер()

	Обещание = НайтиФайлыАсинх(ПутьКПапке, "*.*", Ложь);
	НайденныеФайлы = Ждать Обещание;

	ДобавляемыеФайлы = Новый Массив;
	Для Каждого НайденныйФайл Из НайденныеФайлы Цикл
		Описание = Новый ОписаниеПередаваемогоФайла;
		Описание.Имя = НайденныйФайл.ПолноеИмя;
		ДобавляемыеФайлы.Добавить(Описание);
	КонецЦикла;

	Обещание = ПоместитьФайлыНаСерверАсинх(, , ДобавляемыеФайлы, ЭтаФорма.УникальныйИдентификатор);
	Результат = Ждать Обещание;

КонецПроцедуры
```

## HTTP

С платформы 8.3.21 у `HTTPСоединение` есть асинхронные аналоги методов. Правила те
же: вызывающий метод объявлен `Асинх`, результат получается через `Ждать`, иначе
исключение внутри вызова теряется.
