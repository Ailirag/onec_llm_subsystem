MCP-серверы

MCP (Model Context Protocol) — способ дать модели внешние инструменты: поиск по базе знаний, трекер задач, справочную систему. Подсистема подключается к удаленным MCP-серверам по HTTP, получает список их инструментов и разрешает агенту те из них, что включены в его профиль MCP.

Как подключить сервер

  1. Укажите адрес сервера — полный адрес MCP-точки, например https://example.ru/mcp. Переадресации не выполняются. Адрес http:// принимается, только если отмечено «Разрешить адрес http:// (без шифрования)»: секрет и данные тогда идут открытым текстом.
  2. Выберите тип авторизации и введите секрет:
    • «Токен (Bearer)» — в секрет только сам токен, без слова Bearer;
    • «Логин и пароль (Basic)» — в секрет строку «логин:пароль»;
    • «Ключ в своем заголовке» — имя HTTP-заголовка (например X-API-Key) в поле «Заголовок авторизации», значение — в секрет.
    Секрет хранится отдельно от карточки и после записи не показывается: поле пустое. Пустое поле при записи прежний секрет не меняет; чтобы заменить секрет, введите новый.
  3. Нажмите «Проверить подключение»: карточка запишется, итог появится в полях «Статус подключения», «Версия протокола» и «Текст ошибки».
  4. Нажмите «Загрузить инструменты»: список инструментов сервера попадет в MCP-инструменты. Пропавшие на сервере инструменты выключаются, а не удаляются.
  5. Включите нужные инструменты в профиль MCP с режимом «Выполнять автоматически», укажите профиль в агенте и включите у агента «Агентский режим».

Поля

  • Активен — снимите, чтобы отключить сервер: агенты перестанут получать его инструменты, проверка и загрузка будут отклоняться.
  • Таймаут запроса, с — на каждый запрос к серверу; 0 — 60 секунд. При вызове инструмента действует и предельное время из профиля MCP.
  • Максимальный размер ответа, байт — больший ответ отклоняется; 0 — 5 МБ.
  • Состояние — статус («Доступен» или «Ошибка»), версия протокола, время последней загрузки и текст ошибки. Заполняются проверкой и загрузкой, вручную не меняются.

Как вызываются инструменты

Подтверждения нет: инструмент из профиля с режимом «Выполнять автоматически» агент вызывает сам. Каждый вызов — отдельная сессия с сервером. Ошибка вызова не прерывает ответ: модель получает описание ошибки и продолжает. Вызовы видны в шагах агента в чате и в мониторе операций, а в журнале регистрации — событие «AI.Агент.Инструмент» (без аргументов и результата).

Внешний инструмент выполняется вне информационной базы и со своими полномочиями: подключайте только серверы, которым доверяете. Серверы, инструменты и профили настраивает роль «Администратор MCP»; профиль в агенте указывает пользователь с правом менять агентов.
