Подключения RAG

Справочник (в меню — «RAG») хранит подключение к двум внешним сервисам базы знаний: сервису эмбеддингов, который превращает текст в вектор, и векторной базе Qdrant, где лежат фрагменты текста с их векторами. К подключению привязываются RAG-коллекции.

Что нужно вне 1С

  • Сервис эмбеддингов с API, совместимым с OpenAI: запрос POST на адрес …/embeddings.
  • Qdrant с REST API.
  • Оба сервиса должны открываться с сервера 1С: все вызовы идут с сервера.

Поля

ПолеЧто задает
ВладелецПровайдер, к которому относится подключение; нужен только для группировки.
АктивенВыключенное подключение останавливает векторизацию своих коллекций, а запросы агентов с этими коллекциями завершаются ошибкой.
Адрес сервиса эмбеддинговБез «/embeddings» на конце, например http://сервер:8000/v1.
Модель эмбеддинговИмя модели так, как его ждет сервис. Той же моделью векторизуются и данные, и вопросы: после смены модели коллекции нужно загрузить заново.
Размер вектораСколько чисел в векторе модели (например 768 или 1536). Учитывается при создании коллекции в Qdrant.
Адрес QdrantАдрес REST API без «/» на конце, например http://сервер:6333.
Ключи APIСервису эмбеддингов — заголовком Authorization: Bearer, Qdrant — заголовком api-key. Пусто — без авторизации.
ТаймаутыСейчас не применяются: ожидание ответа — до 3600 секунд при любом значении.

Проверки связи в карточке нет: подключение проверяется первой векторизацией и первым запросом агента. Ошибки пишутся в журнал регистрации (события «AI_RAG» и «AI_Клиент.RAG»).
