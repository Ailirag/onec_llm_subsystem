Обработка для содержания необходимых инструментов разработчика в одном месте.

Страницы:

1. Редактирование объекта - позволяет быстро отредактировать объект БД, достаточно вставить навигационную ссылку в соответствующее поле

2. Консоль кода. Возможности:

1. Позволяет взаимодействовать с объектом страницы Редактирование объекта

2. Встроенное дерево метаданных с отображением синонимов и типов объектов

3. Возможность сохранения алгоритмов, восстановление при открытии.
(Алгоритмы хранятся в файле _conscode в папке с обработкой)

4. Возможность использования в коде функций.

Предусмотрена функция ВызватьФункцию(ИмяАлгоритма, Переменная1, ПеременнаяN) - осуществляет поиск функции в дереве алгоритмов и подставляет параметры
Название функции и алгоритма должны совпадать.

Вид функции:

Функция ПроверкаТест(Фамилия, Имя, Отчество = "Нету")

    Возврат Фамилия + "-" + Имя + "-" + Отчество;
