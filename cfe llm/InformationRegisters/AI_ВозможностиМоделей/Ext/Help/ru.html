Возможности моделей

Какие вложения принимает модель и с какими ограничениями. Записи открываются ссылкой из карточки модели.

Подсистема смотрит на возможности только у модели, которая выбрана «Моделью для разбора файлов» у провайдера, и только на записи с типом API «Responses API»:

  • Ввод изображений — модель читает картинки; Ввод файлов — документы (у провайдеров, кроме Yandex).
  • Максимальный размер файла, байт — предел одного вложения; 0 — 5 МБ для картинок и 20 МБ для документов.
  • Файлов в сообщении, не больше — 0 означает 5. Больше 5 не задавайте: при отправке действует предел в 5 файлов.
  • «Способ передачи» и «Типы файлов MIME» — справочные, подсистема их не читает.

При разборе файлов подсистема сама записывает модели разбора «Ввод изображений» со значениями по умолчанию, поэтому ручная правка этих записей может быть перезаписана.
