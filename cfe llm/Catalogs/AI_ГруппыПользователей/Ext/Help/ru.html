Группы пользователей LLM

Группа пользователей LLM — свой список пользователей подсистемы, чтобы выдавать доступ к агентам сразу нескольким людям. Группа назначается в агенте на вкладке «Доступ», таблица «Группы пользователей»: там же задаются приоритет и, при необходимости, свой профиль данных.

  • Участников добавляет кнопка «Подобрать пользователя» в панели таблицы; для нее нужны права администратора информационной базы. Членство проверяется по идентификатору пользователя: переименование на него не влияет, а пересозданный пользователь — уже другой человек.
  • Выключенная группа («Активна» снят) доступа не дает ни в одном агенте.
  • Приоритет задается не в группе, а в строке назначения конкретного агента. Если пользователь входит в несколько групп, действует строка с наибольшим приоритетом; равный приоритет и разные профили блокируют доступ. Личное назначение важнее любой группы.
  • «Комментарий» — заметка администратора, на доступ не влияет.
  • Изменения действуют сразу, в том числе на уже поставленные в очередь операции: доступ перепроверяется при выполнении.

Группа не выдает ролей и не связана с группами доступа конфигурации. Чтобы показать отдельное AI-действие только части пользователей, используйте вкладку «Кому показывать» места запуска: там работают роли и группы доступа самой конфигурации.
