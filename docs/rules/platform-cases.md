# Типовые ловушки платформы

**Когда читать:** когда поведение платформы расходится с ожиданием, и при ревью
кода, который использует перечисленные механизмы.

Каждый случай по схеме: **проблема → симптом → шаблон**. Список дополняется по той
же схеме, когда обнаруживается новая типовая ловушка; если решение зависит от версии
платформы или БСП, версия указывается явно.

## 1. Проверка значения на заполненность

**Проблема.** Неверный предикат даёт ложные срабатывания на пустых ссылках,
неинициализированных переменных и реквизитах со значением по умолчанию.

**Симптом.** Условие `Если Контрагент <> Неопределено` пропускает пустую ссылку:
пустая ссылка — не `Неопределено`, а полноценное значение ссылочного типа.

**Шаблон.**

```bsl
Если ЗначениеЗаполнено(Контрагент) Тогда
	// ...
КонецЕсли;
```

Для реквизитов формы ссылочного и составного типа сначала скопировать значение в
локальную переменную и проверять её: повторное обращение к свойству формы стоит
дороже, чем кажется по виду кода.

## 2. Длительные операции

**Проблема.** Прямой запуск фонового задания в обход подсистемы длительных операций
БСП оставляет интерфейс без прогресса, без обработки отмены и без сериализации
результата.

**Симптом.** Клиент «висит», индикации нет, кнопка отмены ничего не делает,
результат теряется при обрыве соединения.

**Шаблон.** Запускать через подсистему длительных операций БСП, передавая имя
метода в формате `ИмяОбщегоМодуля.ИмяФункции` либо
`Тип.ИмяОбъекта.ИмяМетода` — без префикса «ОбщийМодуль».

```bsl
Параметры = Новый Структура;
Параметры.Вставить("ДатаНачала", ДатаНачала);
Параметры.Вставить("ДатаОкончания", ДатаОкончания);

ДлительнаяОперация = ДлительныеОперации.ВыполнитьФункцию(
	ПараметрыВыполнения,
	"Отчеты.ПродажиПоПериоду.СформироватьДанныеНаСервере",
	Параметры);
```

На клиенте подключать ожидание завершения средствами того же клиентского модуля
БСП.

**Не передавать в фоновое задание адрес временного хранилища, привязанный к сеансу
формы.** Передавать сериализуемые параметры; результат при необходимости помещать во
временное хранилище изнутри задания.

## 3. Временное хранилище — глобальные функции

**Проблема.** Обращение к временному хранилищу как к объекту.

**Симптом.** «Метод объекта не обнаружен (Поместить)».

**Шаблон.**

```bsl
// Неправильно
Адрес = ВременноеХранилище.Поместить(Данные, УникальныйИдентификатор);

// Правильно
Адрес = ПоместитьВоВременноеХранилище(Данные, УникальныйИдентификатор);
Данные = ПолучитьИзВременногоХранилища(Адрес);
```

## 4. Транзакции в обработчиках событий

**Проблема.** Своя транзакция внутри `ПередЗаписью` или `ПриЗаписи` объекта даёт
вложенное начало транзакции.

**Симптом.** «Транзакция не активна» при откате, частично записанные данные при
ошибке внутри, межсеансовые блокировки.

**Шаблон.** В обработчиках записи объекта свою транзакцию **не открывать**:
платформа уже открыла её. Нужна внешняя транзакция — открывать в вызывающем коде.
Полный разбор и форма записи — [locks.md](locks.md).

## 5. Копирование объектов и табличных частей

**Проблема.** Вызов несуществующего метода копирования.

**Симптом.** «Метод объекта не обнаружен»; потерянные строки табличных частей при
ручном копировании циклом.

**Шаблон.**

```bsl
// Таблица значений
КопияТаблицы = ИсходнаяТаблица.Скопировать();

// Документ как совершенно новый объект
НовыйДокумент = Документы.РеализацияТоваровУслуг.СоздатьДокумент();
ЗаполнитьЗначенияСвойств(НовыйДокумент, ИсходныйДокумент, ,
	"Номер,Дата,ПометкаУдаления,Проведен");
НовыйДокумент.Товары.Загрузить(ИсходныйДокумент.Товары.Выгрузить());
```

Номер, дату, пометку удаления и признак проведённости обязательно исключать: иначе
платформа попытается перезаписать источник.

## 6. Время на сервере

**Проблема.** `ТекущаяДата()` на сервере даёт значение конкретного узла кластера и
игнорирует часовой пояс сеанса.

**Симптом.** Документы с датами «из будущего» или «из прошлого», когда пользователи
работают в разных часовых поясах; расхождение журнала и движений.

**Шаблон.** На сервере — только `ТекущаяДатаСеанса()`. На клиенте `ТекущаяДата()`
допустима, но предпочтительно получать время с сервера.

## 7. Поиск в коллекциях

**Проблема.** Линейный поиск в большой коллекции стоит O(n) на вызов; внутри цикла
получается O(n²).

**Шаблон.**

- До сотни элементов — `Найти()` / `НайтиПоЗначению()` достаточно.
- От тысячи элементов или внутри цикла — индекс на `Соответствие`, поиск становится
  O(1).
- Для частого поиска по нескольким полям — `ТаблицаЗначений.Индексы.Добавить("Поле1, Поле2")`
  и `НайтиСтроки(Структура)`.

```bsl
ИндексПоИНН = Новый Соответствие;

Для Каждого Строка Из ТаблицаКонтрагентов Цикл
	ИндексПоИНН.Вставить(Строка.ИНН, Строка.Контрагент);
КонецЦикла;

Контрагент = ИндексПоИНН.Получить(ИНН);
```

## 8. Внешние компоненты на тонком клиенте

**Проблема.** Синхронное подключение внешней компоненты блокирует интерфейс и не
работает в веб-клиенте.

**Шаблон.** Подключать асинхронно — через `Асинх` / `Ждать` на платформе от 8.3.18
([async.md](async.md)) либо через `ОписаниеОповещения` на более ранних. Отказ
подключения обрабатывать явно: молчаливое продолжение после неудачного подключения
даёт ошибку в другом месте, где причина не видна.

## 9. Управляемые блокировки при проведении

**Проблема.** Отсутствующая или неверная управляемая блокировка приводит к
конфликтам чтения и записи при проведении; несогласованный порядок блокировок между
документами — к взаимоблокировкам.

**Симптом.** Эпизодический «Конфликт блокировок при выполнении транзакции»,
взаимоблокировки под нагрузкой, расхождение остатков после параллельного
проведения.

**Шаблон и полная теория** — [locks.md](locks.md). Кратко: блокировать до чтения;
`Исключительный` для записи, `Разделяемый` только для согласованного чтения;
передавать источник данных, а не перебирать строки; блокировать регистр, а не
документ; никаких диалогов и длительных операций под транзакцией; режим управления
блокировкой конфигурации — управляемый.

## 10. Фоновое задание из внешней обработки

**Проблема.** Длительные операции исполняются на сервере. Если обработка открыта
как внешний файл, а не из справочника дополнительных отчётов и обработок, БСП не
находит обработку на сервере, и запуск в фоне не удаётся.

**Симптом.** «Метаданные не найдены» или «Не удалось получить обработку на сервере»
при запуске фонового задания из формы внешней обработки.

**Шаблон.** Скопировать двоичные данные обработки на сервер через временное
хранилище при открытии формы, сохранить путь серверной копии в реквизите формы и
передать его заданию как имя обработки. Внешнюю обработку определять по полному
имени метаданных объекта.

**Ограничения.** Процедура, исполняемая в фоне, не может использовать реквизиты
формы и табличные части обработки — всё передаётся параметрами. Серверная копия
живёт во временном файле, и её путь нужен до завершения операции.

1. Добавить раздел по схеме «проблема → симптом → шаблон».
2. Явно указать версию платформы или БСП, если решение от неё зависит.
3. Привести минимальный воспроизводимый пример, если он есть.
