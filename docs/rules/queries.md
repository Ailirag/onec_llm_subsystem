# Запросы

**Когда читать:** перед любым непростым запросом и перед его оптимизацией.

Каталог антипаттернов с шаблонами исправления —
[anti-patterns.md](anti-patterns.md). Проектирование регистров, к которым идёт
запрос, — [registers.md](registers.md). Запрос внутри отчёта СКД —
[dcs.md](dcs.md). Границы транзакции вокруг «прочитал и записал» —
[locks.md](locks.md).

## Перед первым ВЫБРАТЬ

1. **Проверить метаданные.** Существование реквизита, его имя и тип. Имена
   реквизитов не угадывать: запрос с несуществующим полем падает на исполнении, а
   не на компиляции, и падает у пользователя.
2. **Найти готовый пример.** Похожий запрос в конфигурации почти всегда есть, и в
   нём уже учтены особенности этих регистров.
3. **Выбрать правильный источник.** Справочник, документ, срез регистра сведений
   или виртуальная таблица регистра накопления (`Остатки`, `Обороты`,
   `ОстаткиИОбороты`). Неверный источник — дефект проектирования, а не повод для
   оптимизации: ускорить запрос к неправильной таблице нельзя.

## Обязательные правила

- **Запросов внутри цикла нет.** Пакетный запрос с временными таблицами.
- **Всегда параметры**: `Запрос.УстановитьПараметр()`, никогда конкатенация в
  текст. Это и защита от подстановки, и кеширование плана.
- **Всегда псевдонимы `КАК`** у полей выборки.
- **Отбор виртуальных таблиц — через параметры**, не через `ГДЕ` после вызова.
- **Промежуточная переменная для результата** обязательна; цепочка вызовов
  запрещена:

```bsl
// Правильно
РезультатЗапроса = Запрос.Выполнить();
Выборка = РезультатЗапроса.Выбрать();

// Неправильно
Выборка = Запрос.Выполнить().Выбрать();
```

  Цепочка не оставляет точки, в которой в отладчике видно, что вернул запрос.

- **`ПЕРВЫЕ N`** когда нужна часть результата, и всегда вместе с
  `УПОРЯДОЧИТЬ ПО`.
- **Тип соединения выводить из требуемой семантики результата**:
  `ВНУТРЕННЕЕ СОЕДИНЕНИЕ` когда строки без соответствия должны исчезнуть,
  `ЛЕВОЕ СОЕДИНЕНИЕ` когда строки источника должны сохраниться — и тогда `NULL`
  обрабатывать явно через `ЕСТЬNULL`.
- **Движения регистров не изменять напрямую** — только через механизм проведения.
- **Все поля отборов и соединений индексировать** в метаданных.

## Форматирование текста запроса

Текст начинается с новой строки на том же уровне отступа, что и объявление
переменной:

```bsl
Запрос = Новый Запрос;
Запрос.Текст =
"ВЫБРАТЬ
|	Контрагенты.Ссылка КАК Ссылка,
|	Контрагенты.ИНН КАК ИНН
|ИЗ
|	Справочник.Контрагенты КАК Контрагенты";
```

## Временные таблицы

- Префикс — `ВТ_`.
- **Временная таблица, участвующая в соединении, обязана быть проиндексирована.**
  Любая `ПОМЕСТИТЬ ВТ_*`, чья таблица затем участвует в `СОЕДИНЕНИИ`
  (обязательно), в дедупликации `ОБЪЕДИНИТЬ` или питает отбор
  `В (ВЫБРАТЬ ...)` по большому множеству — с `ИНДЕКСИРОВАТЬ ПО` по ключам
  соединения.
- Индексировать **2-3 самых избирательных поля**, не весь список колонок.
- **Собрать, проиндексировать, соединить — до тяжёлой работы.** Коррелированный
  подзапрос заменять временной таблицей, собранной один раз. Соединение, питающее
  `СГРУППИРОВАТЬ ПО` по большому источнику, сначала материализовать в
  индексированную временную таблицу, группировать после.

## Дедупликация

`ОБЪЕДИНИТЬ` без `ВСЕ` уже устраняет дубли — `РАЗЛИЧНЫЕ` внутри его операндов
работает вхолостую. Когда дубли невозможны, использовать `ОБЪЕДИНИТЬ ВСЕ`.
`РАЗЛИЧНЫЕ` вместе с `СГРУППИРОВАТЬ ПО` по тем же полям избыточно.

## Сверка перед сдачей многопакетного запроса

- у каждой временной таблицы, используемой далее в `СОЕДИНЕНИИ` / `ОБЪЕДИНИТЬ` /
  `В (ВЫБРАТЬ ...)`, есть `ИНДЕКСИРОВАТЬ ПО` по ключам соединения;
- нет `РАЗЛИЧНЫЕ` внутри операндов `ОБЪЕДИНИТЬ` и поверх `СГРУППИРОВАТЬ ПО`;
- коррелированные подзапросы заменены индексированной временной таблицей и
  соединением;
- периодичность виртуальных таблиц согласована с ключами соединения;
- `ВЫРАЗИТЬ` не стоит в левой части условия `ГДЕ` — это отключает индекс.

Сверку выполнять по пунктам, а не «в целом»: пропущенный `ИНДЕКСИРОВАТЬ ПО` не
виден в результате запроса и обнаруживается только под нагрузкой, когда объём
данных вырос.
