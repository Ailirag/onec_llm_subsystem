# Инструкции для пользователей

В проекте включены два связанных механизма документации:

- встроенная справка 1С по F1 (`userHelp.enabled`): новый пользовательский
  объект без непустой русской страницы справки останавливает фазу `Compile`;
- пошаговые инструкции (`userGuides.enabled`): сценарий проходит по живой базе,
  снимает интерфейс и собирает самостоятельный HTML-документ.

Сценарии пошаговых инструкций лежат в `tests/web-ui/guides`. Рядом со сценарием,
который участвует в выпуске, хранится паспорт `*.guide.json`: он связывает
инструкцию с задачей и объектами встроенной справки.

## Сборка одной инструкции

Сначала опубликуйте стенд текущей ветки, затем соберите сценарий:

```powershell
.\tools\Publish-WebTestStand.ps1
.\tools\Build-UserGuide.ps1 -Scenario knowledge-bundles
```

Результат появится в `.build/guides/knowledge-bundles/index.html`. Явный
локальный `-Url` допустим только для публикации, зарегистрированной за текущей
веткой: это не даёт случайно снять чужую или устаревшую базу.

## Цикл инструкций по релизу

Цикл включён параметром `releaseGuides.enabled`. Манифест релиза можно передать
явно, пока в проекте нет интеграции с трекером:

```powershell
.\scripts\workflow\Invoke-ReleaseGuides.ps1 `
  -Release 2026.09 `
  -Manifest .\release-guides.json
```

Он выбирает паспорта по ключам задач, проверяет указанную в них F1-справку,
собирает инструкции и формирует сводку в `.build/releases`.

Полный контракт сценариев, паспорта и доступные помощники описаны в
[`tests/web-ui/guides/README.md`](../tests/web-ui/guides/README.md).

Старые сценарии `contract-fill` и `batch-queue` пока остаются в
`tests/ui/guides`: они используют прежний проектный runtime для стенда
Документооборота и не входят в новый релизный цикл этого репозитория.
