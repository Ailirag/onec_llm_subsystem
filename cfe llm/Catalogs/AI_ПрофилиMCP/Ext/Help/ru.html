Профили MCP

Профиль MCP — явный список внешних инструментов, разрешенных агенту. Профиль указывается в агенте в поле «Профиль внешних MCP-инструментов» и действует только при включенном агентском режиме.

Разрешенные инструменты

В таблице — MCP-инструменты и режим каждого:

  • Выполнять автоматически — модель получает инструмент и вызывает его сама, без вопросов.
  • Требовать подтверждение (пока не поддерживается) — подтверждения в подсистеме нет, поэтому такой инструмент модели не передается: сейчас это то же, что «Запрещено».
  • Запрещено — инструмент не передается и не вызывается.

Чего нет в профиле, агенту недоступно, даже если инструмент есть на сервере. Не добавляйте один инструмент дважды.

Пределы

  • Максимум вызовов за ответ — сколько раз агент может вызвать MCP-инструменты, отвечая на один вопрос; неудачные вызовы тоже считаются. 0 — 10. Сверх лимита модель получает ошибку.
  • Предельное время вызова, с — на каждый вызов отдельно, вместе с подключением к серверу; 0 — 120 секунд.
  • Предельный размер результата, байт — на каждый вызов отдельно; больший результат модели не передается, она получает ошибку. 0 — 1 МБ.
