## Контракт проекта

Заполняется, только если в MR затронут хотя бы один файл контракта:
`.1c-workflow.json`, `.1c-workflow.defaults.json`, `.1c-workflow.lock.json`,
`AGENTS.md`, `CLAUDE.md`, `.gitattributes`, `.gitignore`,
`.claude/settings.json`, `docs/`, `scripts/`, `tools/`, `.gitlab/`,
`.gitlab-ci.yml`, `tests/test-maintenance.json`, `artifacts/`.

- [ ] Файлы контракта не затронуты — остальные пункты раздела не заполняются
- [ ] Шаги gate `settings-not-weakened` и `codeowners-covers-contract` пройдены
- [ ] Изменение одобрено владельцем из `CODEOWNERS`, и это не самоодобрение автора
- [ ] Планка проверки не понижена

Понижение планки объявляется в `.1c-workflow.json` массивом `contractWeakening`
с полями `setting`, `reason`, `decidedBy`, иначе gate не пропустит. Здесь —
назвать, что именно перестало проверяться и чем это компенсировано.
«Временно» без даты возврата не считается ответом: временных послаблений
процесса не бывает, бывают забытые.
