# Структура модулей

**Когда читать:** перед созданием нового модуля и перед перестройкой
существующего. Единственный источник истины по именам областей и обязательным
директивам препроцессора.

Имена областей — русские, по конвенции БСП. Английские (`Public` / `Internal` /
`Private`) не использовать — кроме конфигурации, которая целиком ведётся в
английской локали с единообразными областями во всём коде.

## Общий модуль

```bsl
#Область ПрограммныйИнтерфейс

#КонецОбласти

#Область СлужебныйПрограммныйИнтерфейс

#КонецОбласти

#Область СлужебныеПроцедурыИФункции

#КонецОбласти
```

- `ПрограммныйИнтерфейс` — экспортные процедуры и функции, которые может вызывать
  любой модуль конфигурации.
- `СлужебныйПрограммныйИнтерфейс` — экспортные методы, предназначенные только для
  модулей самого проекта; сторонний код их не вызывает.
- `СлужебныеПроцедурыИФункции` — внутренние помощники, никогда не `Экспорт`.

## Модуль объекта и модуль менеджера

```bsl
#Если Сервер Или ТолстыйКлиентОбычноеПриложение Или ВнешнееСоединение Тогда

#Область ПрограммныйИнтерфейс

#КонецОбласти

#Область ОбработчикиСобытий

#КонецОбласти

#Область СлужебныеПроцедурыИФункции

#КонецОбласти

#КонецЕсли
```

Внешний блок препроцессора **обязателен**. Без него модуль пытается
компилироваться в клиентских контекстах, где серверных методов нет, и отказ
приходит на первом обращении из тонкого клиента, а не при компиляции.

## Модуль формы

```bsl
#Область ОбработчикиСобытийФормы

#КонецОбласти

#Область ОбработчикиСобытийЭлементовШапкиФормы

#КонецОбласти

#Область ОбработчикиСобытийЭлементовТаблицыФормыИмяТаблицы

#КонецОбласти

#Область ОбработчикиКомандФормы

#КонецОбласти

#Область СлужебныеПроцедурыИФункции

#КонецОбласти
```

Все пять областей обязательны, даже пустые. На каждую таблицу формы — своя
область `ОбработчикиСобытийЭлементовТаблицыФормы<ИмяТаблицы>`, где `<ИмяТаблицы>`
заменяется фактическим именем.

## Общие правила

- Области **внутри** процедур и функций запрещены.
- Псевдообласти комментариями запрещены — только `#Область` / `#КонецОбласти`.
- Канонические области не переименовывать, не удалять и не менять порядок. Пустая
  область остаётся пустой: постоянное место для кода дешевле, чем поиск, куда его
  положить.
