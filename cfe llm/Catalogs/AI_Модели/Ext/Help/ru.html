Модели

Модель принадлежит провайдеру. Обычно модели не заводят руками: их загружает кнопка «Загрузить модели» в карточке провайдера. Модель выбирается в сценарии, в чате и в песочнице.

Поля

ПолеЧто задает
Код модели в APIИдентификатор, который уходит сервису в запросе: gpt-4o, deepseek-v4-flash и т. п. У Yandex можно указать короткий код — полный адрес gpt://… соберется из Folder ID. Не переименовывайте загруженную модель: при следующей загрузке появится дубль.
ПровайдерЧья это модель. В чате и в настройках модель предлагается только вместе со своим провайдером.
Каталог Yandex Cloud (Folder ID)Только для Yandex: из него собирается адрес модели, без него не работают OCR и модель разбора файлов. Пусто, если в коде модели уже полный адрес gpt://…. Другим провайдерам не нужен.
Программный идентификаторУникальный код модели для обращения из программ; заполняется при загрузке. Сама подсистема его не использует.
Справочно: контекстное окно, ценаДля людей: подсистема эти значения не проверяет и стоимость не считает.
ОписаниеДля чего подходит модель. У моделей Z.AI повторная загрузка заменяет текст описанием из каталога.

Возможности модели

Ссылка в карточке открывает возможности модели: какие вложения она принимает и с какими ограничениями. Они важны только для модели, которая выбрана «Моделью для разбора файлов» у провайдера.
