# Компоновка управляемых форм

**Когда читать:** когда форма создаётся с нуля и требования не задают расположение
элементов.

Это знание о компоновке; оно применимо независимо от того, правится форма через
Конфигуратор, EDT или XML. Вход — [forms.md](forms.md).

Имена групп и элементов ниже — реальные идентификаторы, а не описания: их следует
использовать как есть.

## Архетипы форм

### Форма документа

```
ГруппаШапка (горизонтальная, две колонки)
├─ Левая (вертикальная): ГруппаНомерДата, Контрагент, Договор
├─ Правая (вертикальная): Организация, Подразделение, ЦеныИВалютаНадпись
ГруппаСтраницы
├─ Товары: таблица Объект.Товары
├─ Услуги: таблица Объект.Услуги (если есть)
└─ Дополнительно: прочие реквизиты
ГруппаПодвал (вертикальная)
├─ ГруппаИтоги (горизонтальная): Всего, НДС, Скидка
└─ КомментарийОтветственный (горизонтальная): Комментарий, Ответственный
```

Типичные события: `ПриСозданииНаСервере`, `ПриЧтенииНаСервере`, `ПриОткрытии`,
`ПередЗаписьюНаСервере`, `ПослеЗаписиНаСервере`, `ПослеЗаписи`,
`ОбработкаОповещения`.

### Форма обработки

```
Параметры (вертикальная)
├─ группа полей ввода: Организация, Период, режимы работы
├─ информационные надписи
Рабочая область
├─ таблица данных либо страницы
ГруппаКнопок
├─ Выполнить (основная кнопка)
└─ Закрыть (стандартная команда)
```

Режим открытия окна для диалога — блокировка окна владельца.

### Форма списка

```
ГруппаОтборы (всегда горизонтальная)
├─ ГруппаОтбор<Поле> (горизонтальная): флажок и поле ввода на каждый отбор
Список (таблица, динамический список)
├─ колонки полями надписи, не полями ввода
```

Особенности: автосохранение данных в настройках включено, чтобы отборы
запоминались; на каждый отбор — пара реквизитов `Отбор<Поле>` (значение) и
`Отбор<Поле>Использование` (булево, флажок).

### Форма элемента справочника

Простая:

```
ГруппаРеквизитов (горизонтальная)
├─ Наименование
└─ Код (если нужен)
```

Сложная:

```
Главное (вертикальная)
├─ Наименование
├─ ГруппаПараметры (горизонтальная, две колонки)
│  ├─ левая: основные реквизиты
│  └─ правая: второстепенные реквизиты
└─ ГруппаДополнительно (вертикальная)
```

### Помощник

```
ГруппаСтраницы (страницы, ПриСменеТекущейСтраницы)
├─ Шаг 1: описание и параметры
├─ Шаг 2: основная работа
└─ Шаг 3: результат
ГруппаКнопок (горизонтальная)
├─ Назад, Далее (основная кнопка), Выполнить
└─ Закрыть (стандартная команда)
```

## Именование

### Группы

| Назначение | Имя | Вид |
|---|---|---|
| Шапка | `ГруппаШапка` | горизонтальная |
| Левая колонка шапки | `ГруппаШапкаЛевая` | вертикальная |
| Правая колонка шапки | `ГруппаШапкаПравая` | вертикальная |
| Номер и дата | `ГруппаНомерДата` | горизонтальная |
| Подвал | `ГруппаПодвал` | вертикальная |
| Итоги | `ГруппаИтоги` | горизонтальная |
| Кнопки | `ГруппаКнопок` | горизонтальная |
| Страницы | `ГруппаСтраницы` | страницы |
| Предупреждение | `ГруппаПредупреждение` | горизонтальная, невидимая |
| Дополнительный раздел | `ГруппаДополнительно` | вертикальная, свёрнутая |

### Элементы

| Назначение | Имя |
|---|---|
| Поле в таблице | `<Таблица><Поле>` |
| Итог | `Итоги<Поле>` |
| Надпись-гиперссылка | `<Поле>Надпись` |
| Отбор | `Отбор<Поле>` |
| Флажок использования отбора | `Отбор<Поле>Использование` |
| Кнопка команды | `<Команда>Кнопка` |
| Картинка баннера | `<Баннер>Картинка` |
| Надпись баннера | `<Баннер>Надпись` |
| Подменю | `Подменю<Действие>` |

### Обработчики событий элементов

Имя обработчика — имя элемента плюс суффикс события:

| Событие | Суффикс | Пример |
|---|---|---|
| При изменении | `ПриИзменении` | `ОрганизацияПриИзменении` |
| Начало выбора | `НачалоВыбора` | `КонтрагентНачалоВыбора` |
| Нажатие | `Нажатие` | `ЦеныИВалютаНажатие` |
| При окончании редактирования | `ПриОкончанииРедактирования` | `ТоварыПриОкончанииРедактирования` |
| При начале редактирования | `ПриНачалеРедактирования` | `ТоварыПриНачалеРедактирования` |

События уровня формы называются стандартно: `ПриСозданииНаСервере`,
`ПриОткрытии`, `ПередЗакрытием`, `ОбработкаОповещения`.

## Принципы компоновки

1. **Порядок чтения** — сверху вниз, слева направо. Важное сверху.
2. **Две колонки в шапке.** Предметные реквизиты слева (контрагент, склад),
   организационные справа (организация, подразделение).
3. **Кнопки действий внизу.** Основная кнопка помечена как кнопка по умолчанию,
   «Закрыть» — всегда последняя.
4. **Таблицы — основная площадь.** Табличные части занимают большую часть формы,
   обычно на страницах.
5. **Итоги рядом с таблицей**, в подвале, горизонтальной группой, все поля только
   для чтения.
6. **Отборы в отдельной зоне** над списком, горизонтальной группой, парой «флажок и
   поле» на каждый отбор.
7. **Скрытые элементы для состояний.** Баннеры и предупреждения по умолчанию
   невидимы и показываются программно.
8. **Надпись-гиперссылка для подчинённых форм** вместо кнопки — для блоков вроде
   «Цены и валюта», «Учётная политика».

## Приёмы для сложных форм

### Сворачиваемые группы

Для необязательных разделов («Подписи», «Дополнительно», «Прочее») — вертикальная
сворачиваемая группа, по умолчанию свёрнутая.

### Баннер состояния

Группа «картинка и надпись» без заголовка, по умолчанию невидимая, показывается
программно при выполнении условия (просрочено, заблокировано, информационное
сообщение).

### Подменю в командной панели

Связанные команды (печать, отправка, выгрузка) собираются в одну кнопку-меню с
картинкой. Плоский список из десяти кнопок в командной панели не читается.

### Форма без стандартной командной панели

Для диалогов и помощников: стандартная командная панель отключается, кнопки
выставляются вручную, окно открывается с блокировкой всего интерфейса.
